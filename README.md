# Discover Vijayapura — Privacy Policy

A responsive privacy policy page using the supplied policy dated 7 November 2026.

## Contact details

Developer / Organization: Discover Vijayapura

Email: discovervijayapura@gmail.com

Policy sections and contact details are defined in `app/page.tsx`. Styles, mobile layout, and print styles are in `app/globals.css`.

## Develop

Use Node.js 22.13 or newer.

```sh
npm run install:ci
npm run dev
```

## Build

```sh
npm run build
```

Includes linked section navigation, active section tracking, a collapsible mobile contents menu, print support, reduced-motion support, and keyboard focus styles. The page uses no analytics or third-party fonts.
